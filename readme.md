# Odd or Even Checker (JavaScript)

A simple JavaScript program that determines whether given numbers are **Odd** or **Even**. 

## Features
- Uses the JavaScript **Modulo Operator (`%`)** to efficiently check numbers.
- Implements modern JavaScript **Template Literals (Backticks)** to dynamically print variables inside strings.

## Sample Output
For the inputs `5` and `10`, the console will output:
```text
The number 5 is odd.
The number 10 is even.
```
